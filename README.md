# Creativo – Custom WordPress Theme

A fully custom, responsive WordPress theme developed from scratch for a modern creative agency website.

This project focuses on clean UI, responsive design, reusable WordPress templates, dynamic navigation, Customizer options, and Gutenberg compatibility.

---

## 📌 Project Overview

**Creativo** is a custom WordPress theme designed for creative agencies, businesses, freelancers, and digital service companies.

The theme includes a modern and professional interface with multiple custom sections and page templates.

The theme was developed without relying on an existing WordPress theme.

## 📄 Pages & Sections

The theme contains the following pages:

### 🏠 Home
Modern hero section, services overview, projects, content sections and call-to-action areas.

### 👤 About Us
Company introduction, information sections and supporting content.

### 🛠️ Services
Presentation of the services offered by the creative agency.

### 💼 Projects
Portfolio/project showcase with modern card-based layouts.

### 📝 Blog
Dynamic WordPress blog archive for displaying posts.

### 📩 Contact
Contact section with business information and contact interface.

### ❌ 404 Page
Custom-designed error page for unavailable URLs.

### 🔻 Footer
Custom footer containing navigation, services, newsletter and additional information.

## 🎨 WordPress Customizer

The theme includes customizer options that allow administrators to modify the website without editing code.

Available options include:

- Primary Theme Color
- Footer / Dark Color
- Font Family
- Card Corner Radius
- Layout-related styling

Go to:

**WordPress Dashboard → Appearance → Customize**
